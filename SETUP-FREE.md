# Бесплатная установка

Без хостинга, без домена, без карты. Приложение на GitHub Pages, дневник —
в приватном репозитории или в Telegram.

Времени: около 20 минут один раз.

---

## Что и где будет жить

```
Приложение   →  GitHub Pages, публичный репозиторий
                бесплатно, HTTPS, свой адрес, не засыпает

Дневник      →  приватный репозиторий GitHub  ИЛИ  Telegram
                на выбор, можно поменять потом
```

Код приложения секретов не содержит, поэтому его репозиторий публичный —
иначе Pages потребует платный тариф. Дневник лежит **отдельно**, в приватном
месте, куда Pages не заглядывает.

Важно: приложение кэшируется на телефоне целиком. Даже если хостинг однажды
станет недоступен, установленная иконка продолжит открываться и работать —
данные ходят напрямую в хранилище, минуя сайт.

---

## Шаг 1. Приложение на GitHub Pages

Всё делается на сайте, ставить и настраивать ничего не нужно.

1. Заведи аккаунт на [github.com](https://github.com), если его нет.
2. Создай **публичный** репозиторий, например `tonnage`. Галочку
   «Add a README file» ставить не нужно.
3. На странице репозитория нажми **uploading an existing file**
   (или **Add file → Upload files**).
4. Открой на компьютере папку `web`, выдели **всё, что внутри неё**
   (`Ctrl+A`) и перетащи в окно браузера. Именно содержимое папки, а не
   саму папку: `index.html` должен оказаться в корне репозитория.
5. Внизу нажми **Commit changes**.
6. Открой **Settings → Pages**. В разделе **Source** оставь
   **Deploy from a branch**, ниже выбери ветку `main` и папку `/ (root)`,
   нажми **Save**.
7. Через 1–2 минуты обнови страницу Settings → Pages — там появится адрес
   вида `https://твой-логин.github.io/tonnage/`.

> Серверная часть (`server/`) для бесплатного варианта не нужна — она
> пригодится, только если однажды захочешь свой сервер.

> В проекте есть и готовый workflow для автопубликации
> (`.github/workflows/pages.yml`) — он нужен, если положить в репозиторий
> весь проект целиком и публиковать только папку `web`. Для первого раза
> проще способ выше.

## Шаг 2. Место для дневника

Выбери одно. Поменять можно в любой момент: «Ещё → Сменить хранилище».

### Вариант А. Приватный репозиторий GitHub

Каждое сохранение — отдельный коммит, то есть у тебя бесплатно появляется
полная история: можно открыть любую прошлую версию дневника на сайте GitHub.

1. Создай ещё один репозиторий, теперь **приватный**, например `tonnage-data`.
   Пустой, без файлов.
2. Открой [Settings → Developer settings → Personal access tokens →
   Fine-grained tokens](https://github.com/settings/personal-access-tokens)
   → **Generate new token**.
3. Заполни:
   - **Expiration** — максимальный срок, иначе придётся перевыпускать.
   - **Repository access** → Only select repositories → выбери `tonnage-data`.
   - **Permissions** → Repository permissions → **Contents: Read and write**.
     Больше ничего включать не нужно.
4. Нажми Generate и **сразу скопируй токен** — GitHub покажет его один раз.
5. Открой приложение, выбери **GitHub**, впиши `твой-логин/tonnage-data`
   и токен. Готово.

### Вариант Б. Telegram

Дневник приходит файлом в чат с ботом и закрепляется. Прошлые версии остаются
в переписке — их видно и можно скачать с любого устройства.

1. Напиши в Telegram боту **@BotFather**, отправь `/newbot`, придумай имя.
   В ответ придёт токен — скопируй.
2. Найди своего нового бота по имени и отправь ему любое сообщение.
   Без этого бот не имеет права тебе писать.
3. В приложении выбери **Telegram**, вставь токен и нажми **Определить чат** —
   ID подставится сам.

## Шаг 3. На экран iPhone

1. Открой адрес приложения в **Safari** — именно в Safari, из других браузеров
   iOS не ставит.
2. **Поделиться → На экран «Домой»**.
3. Запусти с иконки и подключи хранилище.

Дальше приложение открывается без адресной строки и работает в зале без связи.
Записи уходят в хранилище, когда интернет возвращается.

## Сколько это стоит и где подвох

| | |
|---|---|
| GitHub Pages | Бесплатно. Лимит 100 ГБ трафика в месяц — приложение весит около 200 КБ |
| Приватный репозиторий | Бесплатно, без ограничений по размеру для таких объёмов |
| Telegram | Бесплатно |
| Домен | Не нужен, GitHub даёт адрес и сертификат |

Честный минус один: ты зависишь от чужих правил. GitHub и Telegram могут их
однажды поменять. Поэтому в приложении есть **«Ещё → Скачать копию»** — весь
дневник одним файлом. Скачивай раз в пару месяцев и клади куда-нибудь ещё.

Если когда-нибудь захочется полной независимости, серверная часть уже написана
и лежит в каталоге `server/` — инструкция в [DEPLOY.md](DEPLOY.md). Дневник
переедет туда через «Сменить хранилище», ничего не потеряв.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Actions падают | Открой Actions, посмотри красный шаг. Чаще всего забыли переключить Source на GitHub Actions |
| Страница белая | Проверь, что адрес заканчивается на `/` — например `.../tonnage/`, а не `.../tonnage` |
| «Репозиторий не найден» | Формат именно `логин/название`, без `https://` и без `.git` |
| «Нет прав» у GitHub | У токена должно быть Contents: **Read and write**, и репозиторий должен быть выбран в Repository access |
| Telegram: «чат не найден» | Сначала напиши боту сообщение сам, потом «Определить чат» |
| Не ставится на экран «Домой» | Открыто не в Safari |
| Приложение не обновилось | Закрой его из многозадачности и открой заново |
